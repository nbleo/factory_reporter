Checklist items

The default checklist is empty on purpose - every factory and every product line is checked differently. Add the items you actually walk through here (quality, compliance, testing, commercial), rename them, change the hint or reorder them. A section with no item stays hidden in the form. Recorded notes on existing visits stay untouched.

Form template

This app is not shower-specific. Rename the fields, rewrite the option lists, change the record states and the photo categories to fit a hardware, faucet, tray or glass factory. Lists that show as chips also accept a value typed in the form ("+ Other"), so the visit can record something the template does not know yet. Recorded visits keep their data; only the wording changes.

Private data repository

Fine-grained token with Contents: Read and write on the data repository only. Stored in this browser's local database, never uploaded anywhere except api.github.com.
